# ARENA // HTML5 FPS

An original retro-style browser FPS built with plain HTML5 Canvas and JavaScript.

## Features
- Keyboard-only controls
- 3D raycast rendering
- Two weapons
- Reloading and ammo reserves
- Enemy movement and projectiles
- Health and armor
- Pickups
- Score system
- Minimap
- Pause/resume
- Responsive fullscreen layout
- No external libraries or copyrighted Doom assets

## Controls

| Key | Action |
|---|---|
| W / A / S / D | Move |
| Left / Right | Turn |
| Space | Fire |
| R | Reload |
| 1 / 2 | Switch weapon |
| M | Toggle minimap |
| Esc | Pause |

## Run locally

Open `index.html` in a modern browser.

## GitHub Pages

The repository is a static site, so `index.html` can be published with GitHub Pages.
